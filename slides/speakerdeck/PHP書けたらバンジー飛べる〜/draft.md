# PHP書けたらバンジー飛べる〜

## 概要
これはタイトル通りの記事を書くためのドラフトです。
あくまで記事を書くための情報をまとめただけのものです。
これを読み込んだあなたは、ZennやQiitaに投稿するために作者目線となって記事を作成してください。
記事は同フォルダのarticle.mdに、スライドは`slide-creater`スキルを使ってどフォルダのslide.mdに作成してください。
また、作成する順番としてはslide -> articleでお願いします。
イメージとしては、articleはLTの内容を拡張して書く記事って感じです。
それぞれのセクションごとの文章量を増やし、もしそのネタが技術的側面を持っているのならLT以上に技術要素を追加したり（そのためにセクションを追加したりもする）して欲しいです。

## LTスライドを作るに当たって
slide-createrスキルを使って、slide.mdを作成してください。
適度に画像を挿入したり、コードを挿入したりして、見やすいスライドを作ってください。
また、他のプロジェクトから画像を持ってくるのもOKです。

## 記事を書くに当たって
記事はスライドの各セクションごとを増量し、そして技術的側面を追加して書くことを意識してください。
また、記事の中では画像を使うことはできません。
marmaidなどで図を作ることはできます。

## 記事・スライド共通ドラフト
| 比較項目                   | PHP                           | バンジー                           | 強さ         |
| ---------------------- | ----------------------------- | ------------------------------ | ---------- |
| **Fiber**              | `Fiber` が言語機能として存在する          | ロープは繊維（fiber）でできている            | ★★★★★ 殿堂入り |
| **throw**              | 例外を `throw` する                | 自分自身を崖からthrowする                | ★★★★★ ネタ   |

| **require**            | `require` したものがないとFatal Error | ロープをrequireしないと致命的             | ★★★★★      |
| **include**            | 外部ファイルを `include`             | ハーネスやロープを構成にincludeする          | ★★★★☆      |
| **Throwable**          | `Throwable` はthrowできるもの       | 人間は物理的にthrowable               | ★★★★★ ネタ   |
| **Error**              | 実行時にErrorが起こる                 | 手順を間違えるとErrorになる               | ★★★☆☆      |
| **Exception**          | 通常系から外れた状態                    | バンジーを飛ぶこと自体が日常から見ればException   | ★★★★☆      |
| **try / catch**        | `try` して例外を `catch`           | とりあえずtryして、ロープが落下をcatchする      | ★★★★★      |
| **finally**            | 成功・失敗にかかわらず `finally` が実行される  | finally、地上に戻ってくる               | ★★★★☆      |
| **echo**               | `echo` で出力する                  | 飛んだ人の叫び声がechoする                | ★★★★★ ネタ   |
| **String**             | `string` 型がある                 | バンジーコードも広義にはstringっぽい          | ★★★☆☆ こじつけ |
| **型**                  | PHPには型システムがある                 | ロープにも耐荷重など「型」がある               | ★★★☆☆      |
| **strict_types**       | `strict_types=1` で厳密にする       | 安全基準はstrictであるべき               | ★★★★☆      |
| **Null**               | 値が存在しなければ `null`              | 足元には何もない（null）                 | ★★★☆☆ ネタ   |
| **Nullsafe**           | `?->` でnullでも安全にアクセス          | 安全装備によって「何もない場所」でも安全？          | ★★☆☆☆      |
| **Composer**           | 依存関係を組み合わせてアプリを構成             | ロープ・ハーネス・カラビナ等を組み合わせる          | ★★★★☆      |
| **Dependency**         | ライブラリへの依存                     | ロープへの依存度が100%に近い               | ★★★★★      |
| **autoload**           | クラスを必要時に自動ロード                 | 体重（load）が自動的にロープへ掛かる           | ★★★★☆ ネタ   |
| **interface**          | 実装が従う契約を定義する                  | 人間とロープの接点（interface）がハーネス      | ★★★★☆      |
| **abstract**           | 実装詳細を隠して抽象化する                 | 飛ぶ側はロープの物理計算を知らなくても飛べる         | ★★★★☆      |
